# The Overview Tab

**WB Plugins > Open Graph** opens on the **Overview** tab. It is a status page. Nothing is saved here.

## Status tiles

| Tile | What it counts |
|---|---|
| Published Products | Published products that get social tags when shared |
| Custom Social Text | Published products with their own social title or description |
| Social Output Off | Published products switched off in their Social Media Settings box |
| Sitemap | The date the sitemap files were last written, "Not yet" if never, or "Off" if sitemaps are switched off |

## Current Configuration

A list that says in plain words what happens on your store right now:

| Row | When on, it says |
|---|---|
| Facebook | Shared product links show the product title, image and price |
| X (Twitter) | Product links show a large image card on X |
| Pinterest | Pins carry Rich Pin product data |
| Share buttons | Shown on product pages, and where |
| Product schema | Extra fields are added to WooCommerce's Product schema |
| Organization schema | Search engines are told who runs the store |
| XML sitemaps | Products and categories are listed for search engines |

Any row that is off says **Off** with a **Turn on** link that takes you to the right tab.

The "Organization schema" row says On only when your organization data is really published, which needs both the **Structured Data** switch and **Organization Schema** on. See [Structured Data](../features/structured-data.md).

## Testing Tools

Three buttons that open in a new tab: **Facebook Debugger**, **Google Rich Results** and **LinkedIn Inspector**. Paste a product link into them to see what each one reads. See [Check How a Product Looks When Shared](../how-to/check-how-a-product-looks-when-shared.md).
