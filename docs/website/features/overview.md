# Features Overview

The plugin has five parts. Each one can be changed without touching the others.

| Part | What shoppers or search engines get | Where to control it |
|---|---|---|
| [Social previews](social-previews.md) | A good-looking post when a product link is shared | General tab |
| [Share buttons](share-buttons.md) | Buttons on the product page to share it | Share Buttons tab |
| [Per-product control](per-product-control.md) | Your own social wording, or no social output, for one product | Product edit screen |
| [Structured data](structured-data.md) | Extra facts for Google (logo, profiles, breadcrumbs, brand, codes) | Structured Data tab |
| [Product sitemaps](product-sitemaps.md) | A list of your products and categories for search engines | Sitemaps tab |

## Which pages the plugin works on

| Page | Social preview tags | Share buttons | Structured data | Sitemap |
|---|---|---|---|---|
| Single product | Yes | Yes (automatic) | Yes | Listed |
| Product category | Yes | No | Yes, when the Structured Data switch is on | Listed |
| Product tag | Yes | No | No | Not listed |
| Shop page | Yes | No | Yes, when the Structured Data switch is on | Not listed |
| Cart, checkout, My Account | No | No | No | No |
| Any page or post | No | Only with the [shortcode](../how-to/share-buttons-with-shortcode.md) | No | No |

## Works next to your SEO plugin

If Yoast SEO, Rank Math or SEOPress already prints a tag, this plugin leaves that tag alone and adds only the ones that are missing. Details are in [Use with an SEO Plugin](../how-to/use-with-seo-plugins.md).
